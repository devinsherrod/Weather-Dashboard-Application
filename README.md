# Weather-Dashboard-Application
This is a weather dashboard where the user can enter a city name of their choice and the program will then give them the temperature, condition, wind speed, and humidity for the city of their choice.

Features of my program
- Enter any city to get current weather
- Displays temperature, condition, humidity, and wind speed
- Handles invalid city names with error messages
- Supports cities with spaces such as "New York"

Technologies and Libraries Used
- Java
- JavaFX
- Gson
- Maven
- OpenWeatherMap API
- JUnit
